# Explainable Graph-Based Bot Detection

This repository contains the implementation of a graph-based machine learning framework for social bot detection using the MGTAB dataset.

## Research Task

The current experimental task is binary social bot detection:

- Class 0: Human
- Class 1: Bot

The project uses real expert-annotated labels from MGTAB.

## Models

The experimental pipeline includes:

1. GCN baseline
2. Relational GCN (RGCN) baseline
3. Multi-Relational Attention model

Each model is evaluated using multiple random seeds.

## Dataset

The project uses the MGTAB multi-relational Twitter bot detection dataset.

The dataset files are not stored in this repository.
